# LawMaticDocumentIndex

Локальный индекс текстов документов дел для macOS.

Пакет ведет один файл SQLite `LawMaticDocumentIndex.sqlite`: каталог папок и файлов, извлеченный текст и поиск по нему. Контракт схемы v2: `user_version` 2, идентификатор файла LMDI.

Обычное расположение общей базы: `~/LawMatic Share/LawMaticDocumentIndex.sqlite`. Рядом лежит `manifest.json`.

## Кто пишет и кто читает

Писатель один. Finder открывает базу в режиме `DocumentIndexOpenMode.readWrite`: создает файл, если его нет, ведет каталог, тексты, очередь заданий и эмбеддинги.

Legalic и другие клиенты открывают уже готовую базу в режиме `readOnly`. Такое соединение файл не создает и схему не чинит. Читателю передают снимок: отдельный файл без недописанного журнала WAL.

## Состав индекса

- Рабочие корни, папки, дела и документы.
- Состояние извлечения, тексты, страницы и фрагменты.
- Поиск по словам через FTS5. Перед записью в индекс текст проходит `RussianTextNormalizer`.
- Векторы фрагментов в той же базе. Поиск по смыслу и смешанный поиск выполняются, когда снаружи передан `LocalEmbeddingProvider`. Без провайдера доступен поиск по словам. Модель расчета векторов в этот пакет не входит.
- Расширения Finder в том же файле: факты дела, связи документов, обезличивание. Для чтения ядра контракта они не обязательны.

## Требования

- macOS 14 и новее
- Swift 6.1
- [SQLite.swift](https://github.com/stephencelis/SQLite.swift) от 0.15.4

## Подключение

В Xcode откройте File > Add Package Dependencies и укажите адрес:

https://github.com/lawlabs/LawMaticDocumentIndex

Номера версии у пакета пока нет, поэтому в требовании зависимости укажите ветку `main`. После первого тега зависимость переводят на правило Version.

Продукт для цели приложения: `LawMaticDocumentIndex`.

```swift
import LawMaticDocumentIndex
```
